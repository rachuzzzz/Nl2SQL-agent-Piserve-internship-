# InspectAI — Angular Chat Interface

This is the user-facing application for the InspectAI platform. It provides a modern, interactive chat experience for querying inspection data and visualizing results.

## ✨ Key Features

- **Conversational UI**: Real-time chat with the InspectAI agent, including thought-trace visibility (reasoning steps).
- **Interactive Data Tables**: Server-side paginated tables that handle thousands of rows with ease.
- **Smart Charts**: Automatic visualization of SQL results using **Apache ECharts**.
- **Visual Customization**: A "Column Picker" and "Chart Swapper" that allow users to change X/Y axes or chart types on the fly.
- **SQL Preview**: View the exact SQL generated by the AI for transparency and debugging.

## 🏗️ Core Components

- **Chat Window (`app/components/chat-window`)**: The main interface for sending queries and displaying messages.
- **Chart Display (`app/components/chart-display`)**: Renders ECharts based on the backend's recommendation.
- **Result Table (`app/components/result-table`)**: Displays raw SQL data with pagination and sorting.
- **Debug Panel (`app/components/debug-panel`)**: Shows the LLM's "thoughts" and the generated SQL query.
- **Column Picker (`app/components/column-picker`)**: Allows users to override the AI's chart axis selections.

## 🔌 Service Layer

The frontend communicates with the FastAPI backend via the `ChatService`. It handles:
- **Streaming/Polling**: Fetching responses from the `/api/chat` endpoint.
- **Pagination**: Loading more data via `/api/page` without re-running the full AI pipeline.
- **Custom Charts**: Requesting specific chart types via `/api/chart`.

## 🛠️ Setup & Commands

### Prerequisites
- Node.js 20+
- Angular CLI 21+

### Development
1. Install dependencies: `npm install`
2. Run development server: `ng serve` (runs on `http://localhost:4200`)
3. The frontend is configured to proxy requests to the backend on `http://localhost:8001`.

### Building
```bash
ng build --configuration production
```
The build artifacts will be stored in the `dist/` directory.
